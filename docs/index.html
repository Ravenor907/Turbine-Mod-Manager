Turbine Mod Manager

Mods for your Steam and Heroic games, on a SteamOS handheld, with the controller, in Game Mode.

Get the latest build

Pick a game, add a mod, press Play

  1. Pick a game on the left. Turbine finds your Steam and Heroic games, SD cards included.
  2. Open Get mods, pick a mod, and press A. Some games Turbine knows show good first mods at the top.
  3. Press Play. Turbine checks the game first, puts the mods in, and starts it. For games where Turbine knows where the saves are, it keeps a copy of them first.

Safe by design

  • Turbine only removes files it placed itself. It replaces a game's own file only when the game's rules call for it or you say so, and keeps the original to put back.
  • Nothing in a mod archive is ever run.
  • Removed mods are kept for 7 days. The last setups that worked can be put back.

Any game

Games Turbine knows get their full rules. Every other game gets Basic support: each mod goes where its files show they belong, and Turbine asks you once when it can't tell.

Install

Download TurbineModManager.flatpak from the latest release, open it in Desktop Mode, and add Turbine to Steam to open it in Game Mode. Turbine updates itself after that.
